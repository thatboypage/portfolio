# Portfolio

Personal site of Richard Olanite: a home page and one case-study page per project. Plain HTML and CSS, no framework.

## Edit

All text lives in `build.py`. Change it, then rebuild:

```
python3 build.py
```

To add a photo, save it as `assets/richard.jpg` (portrait, about 600 × 750 px). The About section shows it automatically.

## Deploy

Import this repository in Vercel as a static site (no build command, output directory `.`). Every push to `main` redeploys.
